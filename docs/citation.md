# Citation

Valdrada is developed and maintained by Mehmet Kerem Turkcan. If you use
Valdrada, the compiled city or imagery rendered with it, please cite Valdrada itself:

```bibtex
@software{turkcan2026valdrada,
  author  = {Turkcan, Mehmet Kerem},
  title   = {{Valdrada}: a real-data, real-time digital twin of New York City},
  year    = {2026},
  version = {0.6.0},
  url     = {https://github.com/mkturkcan/valdrada}
}
```

The repository also carries a machine-readable
[CITATION.cff](https://github.com/mkturkcan/valdrada/blob/main/CITATION.cff). Imagery rendered from the compiled
city must carry the attributions listed under [Acknowledgements](acknowledgements.md), in particular
"© OpenStreetMap contributors" and "CARLA Simulator (carla.org), CC BY 4.0".

Releases up to 0.3.0 were published under the name BoundlessNYC; citations of those releases refer to this project.
The reason for the change of name is given at the end of [Acknowledgements](acknowledgements.md).
